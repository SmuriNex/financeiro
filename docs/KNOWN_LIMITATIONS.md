# Limitações Conhecidas

- `public/assets/js/app.js` ainda é grande e precisa ser modularizado.
- Tailwind, Google Fonts e Font Awesome ainda vêm por CDN.
- Não há build com Vite ou empacotamento local de dependências visuais.
- Os testes automatizados ainda cobrem mais cenário anual do que fluxos pequenos isolados.
- Backup/restauração ainda depende de exportação/importação manual.
